10 Core JavaScript Topics

Key theoretical principles and clean ES6+ syntax patterns.

Topic 01

Scope & Hoisting

`let` & `const` enforce block scope and prevent accidental variable re-declaration, unlike function-scoped `var`.

const APP_ID = "JS_01";
let count = 0;
Topic 02

Arrow Functions

Provides compact syntax and lexically retains the `this` value of its enclosing execution context.

const add = (a, b) => a + b;
Topic 03

Destructuring

Directly extracts properties from objects or elements from arrays into discrete local bindings.

const { name, age } = user;
const [first, ...rest] = list;
Topic 04

Rest & Spread (...)

Spread expands arrays/objects into individual items; Rest collects variable arguments into an array.

const merged = { ...obj1, ...obj2 };
const sum = (...n) => n.reduce((a,b)=>a+b);
Topic 05

Promises

Handles asynchronous operations with clean `.then()` chaining, avoiding deeply nested callbacks.

fetchData()
  .then(res => render(res))
  .catch(err => log(err));
Topic 06

Async / Await

Syntactic sugar built on top of Promises enabling asynchronous code to read like synchronous code.

async function init() {
  const res = await fetchData();
}
Topic 07

Optional Chaining & ??

`?.` prevents null pointer errors during lookup; `??` supplies fallback defaults specifically for nullish values.

const city = user?.address?.city ?? "N/A";
Topic 08

Higher-Order Methods

Functional array utilities like `map`, `filter`, and `reduce` returning transformations immutably.

const evens = arr.filter(x => x % 2 === 0);
Topic 09

Closures

A function that retains access to variables from its outer enclosing scope even after termination.

function counter() {
  let c = 0;
  return () => ++c;
}
Topic 10

ES6 Map & Set

`Set` automatically eliminates duplicates; `Map` allows any object or primitive as dictionary keys.

const unique = [...new Set(arr)];
